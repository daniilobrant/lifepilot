Erster öffentlicher Quellrelease von LifePilot auf Basis der Runtime 0.25.16.

- Wochenplanung, Kalender, Aufgaben, Fristen und Projekte.
- Pilot-Chat, Posteingang, Bestellungstracker, Finanzen und Abos.
- Reiseplanung, Outfit-Assistent, Bewerbungen, Vorrat und Einkauf.
- Anleitung für macOS, Versionsverlauf und Galerie aus einem isolierten, synthetischen Testprofil.

Der Release enthält keine persönliche Datenbank oder Zugangsdaten. Das Testprofil kann bei explizit gestarteten Modellfunktionen externe Dienste kontaktieren.
